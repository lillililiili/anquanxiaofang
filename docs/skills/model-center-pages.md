# Model Center Pages Skill

## 适用场景

新增或修改“大模型中台”相关页面时，必须遵守本 Skill。

目标页面：

- `/model-center`
- `/model-center/knowledge`
- `/model-center/hazard-graph`
- `/model-center/expert-rules`

## 导航规则

- 顶部或侧边导航中的“知识库”应归入“大模型中台”菜单下。
- 大模型中台菜单下必须包含：
  - 知识库
  - 隐患图谱
  - 专家规则库
- 不改变既有路由，新增页面也要保持导航可达。

## 知识库页面

页面目标：管理消防与用电安全检查知识，为 AI 识别、检查依据检索、整改建议生成、报告生成提供知识支撑。

必备结构：

- 顶部工具栏
- 顶部筛选区
- 指标卡
- 左侧知识库分类树
- 中间知识文档列表
- 右侧知识详情
- 底部最近更新记录

必备交互：

- 查询：过滤文档列表并提示查询完成。
- 重置：恢复默认筛选。
- 新建知识库：打开弹窗，字段包含名称、类型、适用场景、负责人、描述。
- 同步知识库：当前选中知识库显示同步中，完成后变为已更新。
- 上传文档：打开弹窗，确认后追加 mock 文档。
- 查看、引用、编辑、关联隐患、下载、删除均有反馈。

## 隐患图谱页面

页面目标：沉淀隐患、风险、依据、整改建议、案例之间的关系。

必备结构：

- 顶部筛选区
- 左侧图谱分类和高频隐患
- 中间 SVG/div 图谱画布
- 中间关系明细表
- 右侧关联知识、相似案例、风险提示

必备交互：

- 点击分类、高频隐患、图谱节点、关系表行时联动详情。
- 中心节点“配电箱未关闭”突出。
- 放大、缩小、适配、全屏可用。
- 查询、重置、新建图谱、导出图谱有反馈。

## 专家规则库页面

页面目标：沉淀消防、电气、临时用电、动火作业、物业巡检等专家判断规则。

必备结构：

- 顶部筛选区
- 左侧规则分类树
- 中间规则列表
- 右侧规则详情/编辑面板
- 底部版本记录

必备交互：

- 点击分类过滤规则列表。
- 查看：切换右侧详情。
- 编辑：右侧进入编辑状态。
- 停用/启用：状态变化。
- 复制规则：生成草稿。
- 删除：二次确认后删除。
- 保存、发布、测试、查看版本有反馈。
- 规则测试弹窗返回是否命中、命中规则、风险等级、建议动作。

## Mock 数据

不得接真实后端、真实大模型、真实图数据库、真实规则引擎。

本地 mock 数据文件：

- `src/data/modelCenterKnowledgeMock.ts`
- `src/data/modelCenterHazardGraphMock.ts`
- `src/data/modelCenterExpertRulesMock.ts`

## 禁止事项

- 页面不能像普通文档管理后台，要体现安全检查知识库、隐患图谱、专家规则库的业务关系。
- 不出现“Demo / 演示数据 / 演示模式”等字样，除非用户明确要求。
- 不使用真实接口。
- 主按钮不使用非蓝色。

## 验收

- 三个页面均可打开。
- 左中右联动正常。
- 查询、重置、新建、上传、同步、查看、引用、关联、删除都有反馈。
- `npm run build` 通过。
