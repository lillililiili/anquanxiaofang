# PPT ZIP 图片安插质量

## 核心规则

- 除非用户明确要求，不重新生成图片。
- 除非用户明确要求，不重做 PPT。
- 用户提供的 ZIP 图片是唯一可信图片源。
- 如果 ZIP 同时包含单页图片和总览图/宫格图，只使用单页图片。
- 不得把总览图/宫格图插入任何页面，除非用户明确要求。
- 按页码或稳定文件名前缀把图片映射到页面。
- 保持图片比例，不拉伸、不压扁。
- 不遮挡重要文字、页码、标题或版式元素。
- 除非用户明确要求覆盖，否则输出新文件。

## 遮罩规则

- 只在用户明确要求的位置加暗色遮罩。
- 如果只有第 1 页应有遮罩，则第 2 页到最后一页不得有暗色或半透明图片遮罩。
- 如果加了遮罩，文字必须清晰可读。

## 文案规则

- 保留原 PPT 文案，除非用户要求修改。
- 用户纠正流程步骤或标签后，要同时检查可编辑文本层和渲染预览。
- 如果业务流程是自动化或 AI 驱动，不要凭空加入人工上报等手工步骤。

## 必做校验

交付前必须验证：

- PPT 页数。
- PPT 内媒体图片数量。
- 源单页图片数量。
- PPT 媒体图片与源图片的 SHA256 hash 匹配数。
- 禁用的总览图/宫格图在 PPT 中的 hash 匹配数。
- 遮罩范围是否正确。
- 生成渲染预览或 contact sheet。
- PPT 能正常打开。

24 页示例验收值：

- `SlideCount = 24`
- `PptMediaCount = 24`
- `SourceImageCount = 24`
- `ExactHashMatches = 24`
- `OverviewImageMatches = 0`

## 视觉 QA

- 生成逐页预览或 contact sheet。
- 检查图片亮度和遮罩范围。
- 检查图片比例。
- 检查文字、页码、标题、底部说明没有被遮挡。
- 检查没有任何页面误用总览图/宫格图。

## 异常处理

- ZIP 单页图片不足：停止并报告数量不匹配。
- ZIP 图片过多：识别目标单页图，排除隐藏文件、缩略图、总览图。
- PPT 被打开或锁定：输出新文件；如果必须覆盖，提示用户关闭后重试。
- 文件名排序不明确：优先用数字前缀推导顺序，无法判断时询问映射关系。
