# AI 知识中台页面

## 目标

AI 中台页面应展示知识、规则、图谱关系、案例、风险评分和建议如何支撑业务决策。页面不能看起来只是普通文档管理表格。

## 知识库页面模式

推荐结构：

- 顶部工具栏
- 筛选区
- 指标卡
- 左侧分类树
- 中间知识/文档列表
- 右侧详情面板
- 最近更新表格

预期交互：

- 查询过滤列表。
- 重置恢复默认条件。
- 新建打开包含真实字段的弹窗。
- 同步显示同步中，完成后更新状态。
- 上传后追加本地/mock 文档记录。
- 查看后更新详情面板。
- 引用/加入依据后更新引用状态或给出确认。
- 更多菜单包含编辑、关联、下载、删除。
- 删除需要二次确认。

## 知识图谱页面模式

推荐结构：

- 顶部筛选区
- 左侧图谱分类和高频实体/问题
- 中间 SVG 或 div 节点图谱画布
- 关系明细表
- 右侧关联知识、相似案例、风险/建议面板

预期交互：

- 点击分类、实体、节点、表格行时更新当前节点和详情面板。
- 中心节点需要突出。
- 放大、缩小、适配、全屏控制可用。
- 导出图谱要有可见反馈。

## 专家规则库页面模式

推荐结构：

- 顶部筛选区
- 左侧规则分类树
- 中间规则表格
- 右侧规则详情/编辑面板
- 版本记录

预期交互：

- 点击分类过滤规则表。
- 查看更新详情面板。
- 编辑进入编辑状态。
- 启用/停用改变状态。
- 复制生成草稿。
- 保存、发布、测试、查看版本都有反馈。
- 测试弹窗返回命中状态、命中规则、风险等级和建议动作。

## 数据规则

- 除非用户明确要求真实后端，否则使用本地 mock 数据。
- 不要误接真实模型、图数据库、规则引擎或外部 API。
- mock 数据要足够丰富，让页面看起来像真实可运营系统。

## 验收

- 左、中、右面板联动。
- 操作能改变状态或打开有意义界面。
- 页面能表达知识、规则、风险、建议、案例和报告之间的关系。
- 如修改了代码，构建通过。
