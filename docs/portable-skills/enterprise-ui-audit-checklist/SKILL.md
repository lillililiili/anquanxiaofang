# 企业级 UI 自查清单

## 布局

- KPI 卡片是否使用 CSS Grid。
- KPI 是否没有单个卡片孤立掉行。
- 10 个 KPI 是否为 5 列 x 2 行。
- 同一行图表卡片是否等高。
- 筛选区、KPI、图表、表格、详情面板之间是否统一 16px gap。
- 左右栏比例是否稳定。
- 1440px 下是否没有整页横向溢出。
- 1920px 下是否没有大面积空白。

## 字体

- 页面标题是否接近 22px / 600。
- 卡片标题是否接近 16px / 600。
- 表头是否接近 13px / 600。
- 表格正文是否接近 13px / 400。
- 是否滥用 `font-bold`、`font-extrabold`、`font-black`、`text-black`。
- 详情面板 label 和 value 是否区分清楚。

## 表格

- 表格是否有稳定列宽。
- 宽表格是否在内部滚动容器中。
- 长文本是否使用省略或两行截断。
- 操作列是否没有挤压重要内容。
- 是否没有文字竖排、重叠、大面积换行。

## 交互

- 每个重要按钮是否有真实作用。
- 反馈可以是 Toast、弹窗、状态变化、数据变化、文件生成或路由跳转。
- Toast 不能替代真实业务动作。
- 查询和重置是否真正改变筛选条件和结果。
- 新增、上传、同步、导出、删除、编辑、查看是否都有清晰反馈。
- 破坏性操作是否二次确认。

## 交付

- 检查 1440px 和 1920px。
- 可行时检查浏览器控制台是否有新增错误。
- 运行项目构建命令。
- 最终回复说明改了什么、验证了什么、是否还有剩余风险。
