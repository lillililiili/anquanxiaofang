# 全系统科技蓝主题变更说明

本次目标：全系统采用沉稳、低饱和度的科技蓝，保持政企检查服务平台的专业感。

## 视觉规范

- 深灰蓝导航：`#14283f`；主按钮钢蓝：`#356b9b`；交互强调：`#376b9a`。
- 页面背景：`#eef2f6`；内容卡片：白色；次级区域：`#f5f7fa`。
- 正文：`#34465b`；辅助文字：`#66788c`；细边框：`#dce3eb`。
- 风险使用浅底红、橙、绿标签；科技感通过细线、图谱点阵、数据对齐和界面层次呈现。
- 表格正文 13px / 400，卡片标题 16px / 600；卡片使用小圆角和轻阴影。
- 视频画面与控制条维持深色，确保叠层文字可读。
