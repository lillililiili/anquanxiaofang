# 隐患图谱工作区调整实施计划

**Goal:** 将已确认的图谱主区、右侧分析栏和底部紧凑关系表应用于 5186 独立 demo，保留现有数据、入口、字段和操作。

**Architecture:** 只调整 `HazardGraphCompletePage`，新增独立、带页面前缀的样式文件。共用选中节点和关系状态，联动图谱、详情、表格；不影响其他原型页面。

## 约束

- 深色导航与图谱，浅色表格和详情，主按钮蓝色。
- 不连接后端，不删除已有节点、关系、知识和案例数据。
- 保留项目、类型、风险、场景、日期、关键词筛选及所有原有操作入口。
- 表格正文 13px / 400、行高 48px，长依据缩写展示，完整内容仍可查看。
