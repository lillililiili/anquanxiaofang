# 暗色亮蓝界面实施计划

> 使用 subagent-driven-development 分工执行；用户已确认暗色、较亮蓝色、高级感和更好的布局，直接实施。

**目标：** 将消防巡检平台统一为深海军蓝底、亮蓝强调的工作界面，改善导航与工作台信息层级。

- 原有数据、路由、状态流转和原生日期控件保留；指标与清单的统计范围保持清楚。
- 无新增依赖，不扩大业务范围，不改后端。
