# 深海蓝·琥珀安全视觉升级设计

- 日期：2026-10-03
- 项目：消防与用电安全智能检查服务平台 Demo
- 范围：品牌 Logo、登录入口、图片素材体系、主要卡片视觉接入

## 目标

将当前“深蓝侧栏 + 浅色数据区”的政企 SaaS 界面升级为“深海蓝·琥珀安全”的巡检指挥中心风格。系统继续保持数据可读性与现有业务流程，图片承担品牌识别、场景引导和卡片氛围层，不替代 HTML 数据和业务状态。

## 视觉语言

- 深海蓝：#071B31 / #0D2943，用于登录页背景、品牌区、深色标题带。
- 冷白：#F5F8FB，用于登录面板和内容区的主要文字。
- 钢蓝：#356B9B / #4D86B5，用于主按钮、链接、数据线。
- 琥珀：#D99A3A / #F1B65C，用于风险提示、关键边线和现场扫描光。
- 风险红：只用于高风险和超期状态，不扩散到大面积背景。
- 圆角与阴影沿用现有轻量政企卡片规范，避免全局变成重拟物。

## Logo 方案

生成透明底、无中文文字的图形标志：盾牌轮廓内结合电弧与巡检脉冲，表达消防防护、用电安全和持续检查。图形同时输出彩色主版本与浅色反白版本，页面旁边由 HTML 渲染“消防与用电安全 / 智能检查服务平台”，避免图片文字变形。

## 登录页

新增 `/login` 路由与登录视图。未登录时根路径显示登录页，登录按钮进入现有运营工作台；演示态使用 localStorage 保存状态，不接入真实鉴权。

页面使用左右分栏：

- 左侧约 60%：夜间园区或配电设施巡检主视觉，覆盖深海蓝渐变、扫描线与少量琥珀光，放置品牌主张“每一处风险，都有迹可循”。
- 右侧约 40%：深蓝玻璃感登录卡，包含账号、密码、记住登录、进入演示工作台和素材说明。
- 移动端改为纵向布局，主视觉变为顶部短 banner，登录卡保持完整可操作。

## 图片资产清单

最终素材保存到项目 `public/brand/` 与 `public/ui-backgrounds/`：

1. `brand-mark.png`：透明底主 Logo。
2. `brand-mark-light.png`：深色背景反白 Logo。
3. `login-hero.jpg`：登录页夜间巡检主视觉，右侧保留表单负空间。
4. `dashboard-atmosphere.jpg`：首页运营工作台抽象电气网格背景。
5. `hazard-amber.jpg`：隐患页琥珀扫描光与配电设施氛围图。
6. `helmet-field.jpg`：智能安全帽和现场作业环境氛围图。
7. `report-evidence.jpg`：检查记录、纸张和证据照片桌面场景。
8. `park-overview.jpg`：园区俯瞰与蓝色数据线背景。

所有背景图不嵌入标题、Logo、数字或中文文案；图片说明和风险状态由页面 HTML 渲染。素材在页面中标记为演示氛围图，不冒充现场证据。

## 接入方式

- 新增 `LoginPage` 组件和登录状态控制，保持现有路由与业务页面不变。
- 新增共享 `BrandMark` 组件，替换侧栏现有纯图标品牌区，并用于登录页。
- 在首页、隐患、设备、报告、数据看板卡片中以背景图、缩略图或图片条带接入素材，使用统一渐变遮罩保证文字对比度。
- 新增图片令牌，统一管理图片路径、焦点位置和来源标识。
- 所有图片设置语义化 alt 文本；纯装饰背景使用 aria-hidden。

## 交互与验证

- 登录按钮执行本地演示登录并跳转 `/`，退出或清除演示态后返回 `/login`。
- 卡片中的图片入口继续进入对应业务页面或已有工作流，不增加只弹 Toast 的空按钮。
- 验证 `npm run build`。
- 在桌面宽屏与移动窄屏检查登录页、首页、隐患页的图片加载、文字对比度、溢出与横向滚动。
- 运行时不引入外部图片服务，不修改后端。

## 不在范围内

- 真实账号、权限、单点登录或后端鉴权。
- 删除现有业务数据、路由或演示素材。
- 用图片替代图表、表格和风险标签。
