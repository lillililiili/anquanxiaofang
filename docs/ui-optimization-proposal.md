# 消防与用电安全平台界面优化

日期：2026-09-23。用户已确认暗色、较亮蓝色、更有层次的布局，取代初始蓝白提案。

## 参考

- [SafetyCulture](https://safetyculture.com/platform/)：参考巡检、责任人和整改动作的信息组织。
- [MaintainX](https://www.getmaintainx.com/use-cases/work-order-management)：参考工单优先级、现场证据和设备协同。
- [Ant Design Pro](https://preview.pro.ant.design/welcome/)：企业后台参考入口；未把它的动态页面视为已完成视觉核验的依据。

上述业务参考来自官方介绍；配色与具体布局是本项目的设计选择。

## 本次实施

- 深海军蓝页面 #0B1830、卡片 #122440、浮层 #192E4B、分隔 #243D5E，亮蓝强调 #5AA8FF。
- 主按钮采用 #1A6FDB 搭配白字。高风险红、中风险橙、低风险绿，保留状态文字。
- 侧栏 224px，收起态 72px，按工作空间、智能分析、资源管理分组。
- 工作台使用 12 列网格：四张指标卡；超期隐患与整改进度；任务清单与现场入口；三张趋势/地图卡。
- 精简顶部工具条与演示说明；保留日期和项目筛选的实际范围提示。
- 任务页将查询、重置与筛选项同行对齐，增加清单计数，稳定列宽，窄屏在表格内部滚动。
- 统一业务页、表格、表单、弹窗、图表和地图的暗色语义变量。报告图片保留纸张原貌。

页面标题 22px/600，卡片标题 16px/600，表头 13px/600，表格正文 13px/400；统一 16px 间距。

## 范围

保留既有数据、路由、状态流转与接口；未修改后端、未添加依赖。独立 design-preview 页面不属于本次改版。

验证记录见 [实施计划](superpowers/plans/2026-09-23-dark-blue-ui.md)。
